# Khan Travels 🚗

A responsive travel and cab booking website designed for Khan Travels. The website helps customers explore travel routes, view booking offers, and contact the business easily through WhatsApp.

## 🌐 Project Overview

Khan Travels is a user-friendly travel website designed to provide customers with a convenient way to explore travel services and make booking enquiries.

## ✨ Features

- Responsive design for mobile, tablet, and desktop.
- Attractive homepage and hero section.
- Travel routes and destination information.
- Online booking enquiry section.
- WhatsApp direct contact button.
- First booking special offer banner.
- Mobile-friendly navigation.
- Modern and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Bootstrap Icons

## 🚀 How to Run the Project Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code to run the website locally.

## 🌍 Deployment

This website can be deployed using Render as a Static Site.

1. Push the project to GitHub.
2. Log in to Render.
3. Select **New → Static Site**.
4. Connect your GitHub repository.
5. Set the Publish Directory to `.` if your `index.html` is in the repository root.
6. Click **Deploy**.
